## Overview

**Spendwise** is an intuitive, full-stack personal financial management and budgeting platform designed to simplify expense tracking, financial planning, and analytical reporting. Leveraging **AI-driven insights (Google Gemini / Anthropic Claude)**, real-time chart visualisations, and automated report exports (PDF/CSV), Spendwise enables users to take full control of their financial health with precision and ease.

Built as an **npm Workspaces Monorepo**, the project pairs a modern **Next.js 16 (App Router)** frontend with a robust, scalable **Express & Prisma API** backend.

---

## Key Features

- **Interactive Dashboard & Analytics**: Real-time spending breakdowns, monthly spending trends, and category distribution powered by Chart.js.
- **Expense Tracking**: Add, edit, filter, and categorize daily expenses effortlessly with customizable currency preferences (e.g., LKR, USD, EUR).
- **Smart Budget Management**: Set category-specific monthly budget caps with automated alert thresholds and progress tracking.
- **AI Financial Advisor**: Receive intelligent financial guidance, spending habit breakdowns, and cost-cutting tips generated by LLMs (Google Gemini / Anthropic Claude).
- **Export Reports**: Generate and download comprehensive financial summaries in **PDF** or **CSV** formats.
- **User Preferences & Security**: Profile management, customizable email/alert notifications, avatar upload via Cloudinary, and secure JWT authentication.
- **Dockerized Local Development**: Quick spin-up of backend services and database environments using Docker Compose.
- **CI/CD Pipeline**: GitHub Actions workflows for automated type-checking, Prisma schema validation, and unit/integration test suites.

## Getting Started

### Prerequisites

Ensure you have the following installed on your local machine:
- **Node.js**: `v20.x` or higher
- **npm**: `v9.x` or higher
- **Database**: PostgreSQL database instance (or Docker for MS SQL Server / Postgres)

---

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/HansiAshara/spandwise.git
   cd spendwise
   ```

2. **Install all dependencies** (Root monorepo installation):
   ```bash
   npm install
   ```

---

### Environment Setup

#### 1. Backend Environment Configuration (`apps/api/.env`)
Create a `.env` file inside `apps/api/`:

```env
PORT=5000
NODE_ENV=development
CORS_ORIGIN=http://localhost:3000

# Database Connection
DATABASE_URL="postgresql://postgres:password@localhost:5432/spendwise?schema=public"

# Authentication
JWT_SECRET=your_jwt_secret_key_here
JWT_EXPIRES_IN=7d

# AI Services (Optional - for smart financial insights)
GEMINI_API_KEY=your_google_gemini_api_key

# Media Storage (Optional - for avatar uploads)
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_key
CLOUDINARY_API_SECRET=your_cloudinary_secret

# Email Service (Optional - for password resets & alerts)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_app_password
```

#### 2. Frontend Environment Configuration (`apps/web/.env.local`)
Create a `.env.local` file inside `apps/web/`:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

---

### Database Setup & Migration

Generate the Prisma Client and sync the database schema:

```bash
# Navigate to the API workspace
cd apps/api

# Push schema to database
npx prisma db push

# Seed initial categories and sample data
npm run seed
```

---

### Running the Application

From the **root workspace directory**:

- **Run both backend and frontend in development mode**:
  ```bash
  # Start Backend API (Port 5000)
  npm run dev:api

  # In a separate terminal, start Frontend Next.js (Port 3000)
  npm run dev:web
  ```

- **Access points**:
  - **Frontend UI**: [http://localhost:3000](http://localhost:3000)
  - **Backend API**: [http://localhost:5000](http://localhost:5000)

---

## Docker Deployment (Local Development)

You can run the backend and database using Docker Compose without setting up local database servers manually:

```bash
# Start backend API and database container
docker-compose up -d --build
```

## CI/CD Pipeline

Automated Continuous Integration runs via **GitHub Actions** (`.github/workflows/ci.yml`) on pushes and pull requests to `main`:
- Spins up a temporary PostgreSQL service container.
- Verifies database migrations and seeds.
- Executes full API TypeScript type checks and Jest integration test suites.
- Validates the Next.js production build.
